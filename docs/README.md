# Expense Tracker PWA

A beautiful, modern, mobile-first Expense Tracker Progressive Web App built completely without any frameworks.

## Features
- **100% Offline & Local**: No backend, no login, completely private. Uses IndexedDB for storage.
- **Progressive Web App**: Installable on Android and iOS devices. Works without an internet connection.
- **Modern Design**: Google Material inspired UI with smooth animations, dark/light mode, and fluid micro-interactions.
- **Comprehensive Dashboard**: View income, expenses, savings, and visual charts summarizing your financial health.
- **Transaction Management**: Easily add, edit, and categorize your transactions.
- **Budgets**: Set and monitor category-based spending limits.
- **Data Portability**: Full JSON backup and restore capabilities.

## Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Vanilla CSS with custom properties, flexbox, grid, and modern pseudo-selectors. No Tailwind or Bootstrap.
- **JavaScript (ES6 Modules)**: Vanilla JS. No React, Vue, or Angular.
- **IndexedDB**: Persistent local database in the browser.
- **Service Worker & Manifest**: PWA capabilities.
- **Chart.js**: Locally bundled for rendering charts without a CDN.
