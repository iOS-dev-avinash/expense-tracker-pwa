# Usage Guide

## Navigation
- **Home**: Dashboard showing high-level summary, recent transactions, and quick charts.
- **Transactions**: View, filter, and sort your entire transaction history.
- **Categories**: Manage your custom income and expense categories, including icons and colors.
- **Reports**: Deep dive into your finances with interactive charts and exports.
- **Settings**: Manage data, backups, and app themes.

## Adding Transactions
1. Tap the central **+** button in the bottom navigation bar.
2. Select **Add Income** or **Add Expense**.
3. Fill in the Amount, Category, Date, and any optional details.
4. Tap Save.

## Categories & Subcategories
You can create custom categories and assign specific subcategories to them.
1. Go to the **Categories** tab.
2. Tap the **+** button.
3. Choose a Name, Type (Income/Expense), Icon, and Color.
4. Tap Save.
5. Tap on the newly created category in the list to manage its **Subcategories**.

## Budgets
You can set limits on specific expense categories per month.
1. Go to **Settings**.
2. Tap **Monthly Budgets**.
3. Enter limits for specific categories.
4. Go back to the **Dashboard** to see a progress bar for each active budget.

## Data Backup
Since everything is stored locally, it is highly recommended to export your data regularly.
1. Go to **Settings**.
2. Tap **Export Backup**.
3. Save the `.json` file somewhere safe.
4. You can restore this file on a new device using the **Import Data** option.
