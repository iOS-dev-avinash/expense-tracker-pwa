# Default Categories

The application ships with a pre-configured set of default categories to help users get started immediately.

## Expense Categories

1. **Food & Dining** (Icon: 🍔)
   - Subcategories: Groceries, Restaurants, Fast Food, Coffee
2. **Transport** (Icon: 🚗)
   - Subcategories: Fuel, Public Transit, Taxi/Cab, Flight
3. **Shopping** (Icon: 🛍️)
   - Subcategories: Clothing, Electronics, Personal Care
4. **Housing & Bills** (Icon: 🏠)
   - Subcategories: Rent, Electricity, Water, Internet
5. **Health & Medical** (Icon: 🏥)
   - Subcategories: Doctor, Pharmacy, Insurance
6. **Entertainment** (Icon: 🎬)
   - Subcategories: Movies, Games, Subscriptions

## Income Categories

1. **Salary** (Icon: 💼)
   - Subcategories: Primary Job, Bonus
2. **Investment** (Icon: 📈)
   - Subcategories: Dividends, Interest, Capital Gains
3. **Other Income** (Icon: 🎁)
   - Subcategories: Gifts, Refunds, Side Hustle

Users can edit or delete these default categories (except for hardcoded systemic defaults, if enforced, though currently all categories can be modified) and add their own via the Categories tab.
